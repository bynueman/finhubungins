# 💰 FinHubungins — Finance & Invoice Management System

**FinHubungins** adalah sistem manajemen keuangan berbasis Laravel dan Filament untuk mengelola data pelanggan, layanan, transaksi, serta pencetakan invoice pelanggan Hubungins.

Sistem ini dibuat untuk membantu operasional agency agar proses administrasi, pencatatan, dan penagihan menjadi lebih rapi, cepat, dan profesional.

## 🚀 Overview

FinHubungins digunakan untuk:

- Mengelola data pelanggan
- Mengelola data pengguna jasa Hubungins
- Membuat invoice pelanggan
- Mencetak invoice
- Mencatat layanan yang digunakan pelanggan
- Melacak status pembayaran

## ✨ Features

- Admin panel menggunakan Filament
- Customer management
- Service management
- Invoice management
- Print-ready invoice
- Payment status tracking
- Dashboard admin
- Authentication system

## 🛠️ Tech Stack

- Laravel
- Filament
- PHP
- MySQL
- Tailwind CSS
- Vite

## 📂 Main Modules

### Customer Management
Mengelola data pelanggan atau pengguna jasa Hubungins, seperti nama, kontak, instansi, perusahaan, dan informasi lainnya.

### Service Management
Mengelola daftar layanan Hubungins, seperti website development, branding, design, digital campaign, dan layanan kreatif lainnya.

### Invoice Management
Membuat, mengelola, dan mencetak invoice berdasarkan data pelanggan dan layanan yang digunakan.

### Payment Tracking
Memantau status pembayaran invoice, seperti pending, paid, overdue, atau cancelled.
